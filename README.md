# Глаголы иврита — Hebrew verbs

A trainer of the ~1000 most frequent Hebrew verbs for Russian speakers: the
meaning, then the present, past and future tenses; a menorah of the seven
binyanim, a dictionary and progress stats. The interface is in Russian only.
A static app that works offline (PWA), deployed to GitHub Pages:
<https://dmitryweiner.github.io/hebrew-verbs/>.

Work in progress: see [the plan](plans/2026-11-24-hebrew-verbs.md) (in
Russian).

## Development

```bash
fnm use            # Node from .node-version
npm ci
npm run dev        # dev server
npm run check      # typecheck + lint + unit tests
npm run smoke      # browser smoke (-- --preview for the build and offline)
npm run build      # → dist/
```

See [AGENTS.md](AGENTS.md) for the layout, conventions and the data scripts,
[docs/](docs/) for the documentation.

## Data sources

Verb forms are generated by the app's own conjugator (`scripts/lib/`) and
checked against:

- [English Wiktionary](https://en.wiktionary.org/) conjugation tables
  (CC BY-SA 4.0) — nikud, and the lexical marks of a verb;
- [Hspell](http://hspell.ivrix.org.il/) (AGPL-3.0) — spelling without nikud;
  used by the build scripts and as a test fixture only, nothing of it ships
  with the app;
- [FrequencyWords](https://github.com/hermitdave/FrequencyWords), OpenSubtitles
  2018 Hebrew list (CC BY-SA 4.0) — verb frequency ranks.

Russian translations and aspect pairs are written by hand and reviewed;
their forms are conjugated by [pymorphy3](https://github.com/no-plagiarism/pymorphy3)
(MIT, build scripts only). How the data is made: [docs/data.md](docs/data.md).
