# Этап 0 — проверка источников данных: отчёт

2026-11-24. План: `plans/2026-11-24-hebrew-verbs.md`, раздел 1.

## Итог

Решение 1 подтверждается с уточнением ролей:

- **Формы делает свой спрягатель (C).** Прототип после доработки на первых 50
  глаголах на 50 новых без правок дал 38 глаголов без единого расхождения.
  Остальные 12 — недостающие правила (их конечное число) и лексические
  пометки, а не принципиальные проблемы.
- **Огласовки сверяем с английским Викисловарём (B).** Таблицы есть у
  49/50 и 50/50 глаголов выборок, у ~87 % верхней тысячи (верхняя оценка).
  Плюс Викисловарь даёт лексические пометки глагола (`nochataf`, гласная
  будущего, особый инфинитив) — их можно брать автоматически.
- **Написание без огласовок сверяем с Hspell.** У Викисловаря оно
  ненадёжно (нет удвоения ו/י), у Hspell совпадает с правилами Академии.
- Глаголы без таблицы в Викисловаре и все расхождения — в список на ручную
  проверку. Совсем неправильные (יכול) — таблица вручную.

## 1. Частотность

Работает: верх списка — היה, ידע, עשה, רצה, ראה, חשב, הלך, אמר, בא, דיבר…
Как и ожидалось, нужен ручной проход: в первой сотне ~15 ложных «глаголов»
(נכון, זימן ← זמן, פיעם ← פעם, בטח, רגע, בחור). Служебные слова (של, אחד,
יותר) скрипт уже отбрасывает. **יכול в Hspell как глагола нет** — его и
подобные добавляем руками.

## 2. Викисловарь

- **he.wiktionary** — только сводка по корню (3 л. прош., наст., буд.,
  инфинитив по биньянам). Полных таблиц нет — как источник не годится.
- **en.wiktionary** — таблицы генерирует модуль `{{he-conj}}` по корню,
  биньяну и пометкам; огласовки полные. Есть у 49/50 (нет יכל) и 50/50.
  По всему сайту — 2154 глагольные страницы с таблицей; из верхней 1000
  нашего списка (ещё с мусором) совпало 874, из верхних 300 — 281.
  Нет, например: עסק, התרחק, התעסק, הבחין, נאלץ, הסתבר, נעצר, הפקיד.
- **Написание без огласовок у Викисловаря с ошибками**: התכון вместо
  התכוון, מסים вместо מסיים, מקוה вместо מקווה, תשאר вместо תישאר
  (84 формы из 2570 в двух выборках).
- Условности огласовок: классические — 2 л. мн. прош. אֲכַלְתֶּם (сноска:
  в речи אָכַלְתֶּם), 1 л. будущего перед дагешем — אֵקַּח (у Hspell и
  у меня אֶקַּח / אקח).

## 3. Hspell

49/50 и 50/50 (нет יכל). Вне ошибок Викисловаря расхождений два вида:
литературный инфинитив לאמור (вместо לומר) и 1 л. будущего (выше).
Годится как эталон написания без огласовок.

## 4. Спрягатель

Шаблон биньяна над корнем → фонологические правила (гортанные, хатафы,
слабые корни, ассимиляция, дагеш, вставной патах) → огласованная форма
(классическая) и написание без огласовок по правилам Академии.

|                                               | Разработка (50)                                             | Контроль (50), первый прогон |
| --------------------------------------------- | ----------------------------------------------------------- | ---------------------------- |
| глаголов без расхождений с Викисловарём       | 44                                                          | 38                           |
| форм, расходящихся с Hspell (без огласовок)   | 1 из 1270 (לומר — намеренно)                                | 85 из 1300, в 7 глаголах     |
| форм, расходящихся с Викисловарём (огласовки) | 8: 4 — наст. вр. היה (намеренно нет), 4 — условность אֵקַּח | 138                          |

Разбор 12 контрольных глаголов с расхождениями:

| Причина             | Глаголы                                                                                                                                                         | Что нужно                     |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------- |
| нет правила         | שם (буд. יָשִׂים), ישן (стативный: יָשֵׁן, יִישַׁן), ירה (יִירֶה), הוציא/הביא/נמצא (ל"א вне пааля: הוֹצֵאתִי), נרגע (נִפְעַל с гортанной), התראה (хитпаэль ל"ה) | 6 правил                      |

| баг                 | סיים (סייים), гортанная после префикса в настоящем хифиля                                                                                                       | исправить                     |

Ещё не написано совсем: пуаль, хуфаль, удвоенные корни (הֵגֵן, הִתְמוֹדֵד),
четырёхбуквенные (תִּרְגֵּם). Оценка: ещё 10–15 правил, и примерно у каждого
десятого глагола — пометка (из Викисловаря, где он есть).

## Вопросы на решение

Отвечены 2026-11-24: все четыре — как рекомендовано (решения 15–18 в плане).

1. **Какие огласовки показывать.**
   - (а) Классические, как в словарях, Pealim, Викисловаре: דִּבֵּר, а
     без огласовок — דיבר (полное написание). Рекомендую. Тест данных из
     плана меняется: не «`plain` = `nikud` без огласовок», а «`plain` =
     правила полного написания от `nikud`, и совпадает с Hspell».
   - (б) Смешанные — полное написание с огласовками: דִּיבֵּר. Переключатель
     огласовок просто убирает значки; но такая запись нестандартна и
     неоднозначна (הִתְכַּוֵּון).
2. **Где речь и норма расходятся** (אֲכַלְתֶּם / «ахальтем», אֶקַּח).
   Рекомендую огласовки по норме Академии, транслитерацию — как говорят.
3. **Инфинитив с вариантами** (לומר / לאמור, ליפול / לנפול): основной —
   разговорный, второй — в `variants`. Рекомендую.
4. **Лицензии.** Таблицы и пометки Викисловаря и частоты FrequencyWords —
   CC BY-SA 4.0: в `verbs.json` они попадают как производные данные →
   `verbs.json` под CC BY-SA 4.0 (код — GPL-3.0-or-later), страница
   «Источники» с атрибуцией. Hspell (AGPL) — только в скриптах сборки, его
   формы в приложение не попадают. Рекомендую так.
