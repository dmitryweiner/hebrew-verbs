# Глаголы иврита — план приложения

Статус: этап 0 сделан (отчёт `plans/2026-11-24-stage0-report.md`, решения
15–18), этап 1 — каркас — сделан прямо в `main`; идёт этап 2 (ветка
`stage2-data`, ход — `plans/2026-11-24-stage2-progress.md`, решения 20–24).

Обучающее приложение для русскоязычных: ~1000 самых частотных глаголов иврита,
четыре части по порядку (глаголы → настоящее → прошедшее → будущее), менора
биньянов, словарь, статистика. Только русский интерфейс. Статическое приложение
без сервера → PWA, работает без интернета, GitHub Pages.

Соседи, с которых берём готовое:

- `alef-bet/` — статистика и подбор с весами по ошибкам и давности
  (`stats.ts`, `selection.ts`), раунд, PWA + smoke, интерфейс на русском без i18n.
- `misparim/` — `speech.ts` (поиск голоса иврита), `bidi.ts` (ивритские куски
  внутри русского текста), oxlint + prettier, TS 7.
- `hebrew-train/` — экранная ивритская клавиатура, экран итогов раунда,
  «Повторить ошибки».

## 1. Данные — самая рискованная часть

Нужно для каждого глагола: инфинитив, корень, биньян, перевод(ы) на русский,
полные таблицы настоящего, прошедшего и будущего времени — с огласовками и без.
Плюс частотный ранг.

### 1.1 Частотность

Список словоформ из субтитров OpenSubtitles (`hermitdave/FrequencyWords`,
`he_50k.txt`, CC BY-SA 4.0) — разговорная речь, то что нужно ученику.
Частота глагола = сумма частот всех его форм (без огласовок). Форма, общая
для нескольких глаголов или совпадающая с частым существительным (אוכל —
«ест» и «еда»), делится/штрафуется; верх списка я просмотрю руками, итог
показываю вам списком на утверждение.

Чтобы посчитать частоты, нужны формы для кандидатов (~3–4 тыс. глаголов),
а не только для итоговой тысячи: кандидаты и их формы без огласовок берутся
из источника спряжений (1.2) или из словаря Hspell (AGPL, используется только
скриптом сборки, в приложение не попадает).

### 1.2 Спряжения и переводы

| Вариант                                               | Плюсы                                                                                                     | Минусы                                                                                 |
| ----------------------------------------------------- | --------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| A. Pealim (pealim.com)                                | полные таблицы с огласовками и транслитерацией, есть русские переводы, модель спряжения у каждого глагола | контент защищён авторским правом; без разрешения автора брать нельзя                   |
| B. Викисловарь (he.wiktionary, en.wiktionary)         | CC BY-SA, совместим с GPL-3.0                                                                             | покрытие тысячи глаголов не гарантировано, разметка разнородная, русских переводов нет |
| C. Свой спрягатель по моделям (биньян + группа корня) | полностью свои данные, ~40 моделей покрывают всё                                                          | много частных случаев (гортанные, слабые корни), огласовки — главный источник ошибок   |
| D. Таблицы генерирую я (LLM) + автоматическая сверка  | быстро, переводы на русский сразу                                                                         | возможны ошибки в огласовках; нужна проверка                                           |

Решено: **B + C + D вместе**. Модельный спрягатель (C) — основа; таблицы
Викисловаря (B) там, где есть, — эталон для тестов спрягателя; формы без
огласовок сверяются с Hspell; расхождения разбираю руками. Русские переводы,
транслитерацию кириллицей и русские формы для фраз (1.3) готовлю я (D),
вы просматриваете.

Первый шаг (этап 0) — проверка: беру 50 глаголов из верха частотного списка
и смотрю, сколько из них есть в Викисловаре, сколько расхождений у
спрягателя/Hspell. По итогам — короткий отчёт и окончательный выбор.

### 1.3 Формат

`src/data/verbs.json` — сгенерированный и закоммиченный (это данные, а не
артефакт сборки), скрипт сборки — `scripts/build-verbs.mjs`.

```ts
interface Verb {
  id: string; // стабильный: по нему хранится статистика, менять нельзя
  rank: number; // 1 = самый частотный
  infinitive?: Form; // לֶאֱכֹל; нет у пуаля и хуфаля
  lemma: Form; // заглавная форма: инфинитив, у пуаля/хуфаля — прош. 3 л. м. р. (סֻדַּר)
  root: string[]; // ['א','כ','ל']
  binyan: Binyan; // 'paal' | 'nifal' | 'piel' | 'pual' | 'hifil' | 'hufal' | 'hitpael'
  ru: string[]; // переводы, первый — основной: ['есть', 'кушать']
  present?: Record<PresentSlot, Form>; // ms, fs, mp, fp; нет у היה и т. п.
  past: Record<PastSlot, Form>; // 1s, 2ms, 2fs, 3ms, 3fs, 1p, 2mp, 2fp, 3p
  future: Record<FutureSlot, Form>; // 1s, 2ms, 2fs, 3ms, 3fs, 1p, 2mp, 2fp, 3mp, 3fp
  futureLiterary?: { '2fp': Form; '3fp': Form }; // תֹּאכַלְנָה — только в словаре
  ruForms: RuForms; // русские формы для фраз после ответа
}
interface Form {
  nikud: string;
  plain: string;
  variants?: string[]; // иное полное/неполное написание
  translit: string; // кириллицей: «ле-эхоль»
}
interface RuForms {
  // несовершенный вид + совершенный, где есть пара
  ipf: string; // есть
  pf?: string; // съесть
  present: Record<'1s' | '2s' | '3s' | '1p' | '2p' | '3p', string>; // ем, ешь…
  past: { ipf: Record<'m' | 'f' | 'pl', string>; pf?: Record<'m' | 'f' | 'pl', string> }; // ел / съел
  future: { ipf: Record<RuPerson, string>; pf?: Record<RuPerson, string> }; // будешь есть / съешь
}
```

Русские формы: исходные пары видов пишу я, спряжение — скриптом через
pymorphy3 (MIT, только в сборке), выборочная проверка глазами. В фразе после
ответа — оба вида: «ты (м.) будешь есть / съешь».

Размер: ~1000 × 25 форм ≈ 0,8 МБ JSON, ~150 КБ gzip — загружается
отдельным чанком и кэшируется service worker'ом.

Огласовки — классические (דִּבֵּר), `plain` — полное написание (דיבר), см.
решение 15. Тест данных (`src/data/verbs.test.ts`): `plain` = правила полного
написания от `nikud` и совпадает с Hspell,
буквы корня входят в формы, id и ранги уникальны, у каждого глагола есть
перевод, нет двух глаголов с одинаковым инфинитивом и переводом.

### 1.4 Иллюстрации

У глагола, который можно нарисовать (бежать, есть, писать, спать), есть
картинка; у абстрактного (решать, значить, казаться) — нет, и это явная
отметка, а не пропуск.

- **Эмодзи**, где есть однозначный (🏃 бежать, 😴 спать, ✍️ писать). Для
  старых телефонов без нового эмодзи — SVG-копия Twemoji в `public/emoji/`
  (как в hebrew-train, `scripts/fetch-emoji.mjs`).
- **Своя SVG**, где эмодзи нет или он двусмысленный: схематичный рисунок в
  одном стиле — человечек-палочка и предмет, линии `currentColor` (работает
  в тёмной теме), `viewBox="0 0 128 128"`, без текста и букв (не подсказка),
  до 4 КБ. Файлы — `public/pictures/<id>.svg`, рисую я.
- **Нет картинки** — для абстрактных глаголов.

Данные отдельно от сгенерированного `verbs.json`, чтобы пересборка их не
затирала: `src/data/pictures.json`, по id глагола —
`{ kind: 'emoji', emoji } | { kind: 'svg' } | { kind: 'none' }` и статус
проверки `review: 'pending' | 'ok' | 'redo'` с комментарием.

Тест: у каждого глагола из тысячи есть запись; у `svg` есть файл, файл —
корректный SVG с нужным `viewBox`, без `<text>`, `<script>`, внешних ссылок,
не больше 4 КБ; у эмодзи есть Twemoji-копия; в приложение попадают только
записи со статусом `ok`.

**Проверка человеком.** Страница просмотра только для дев-сервера
(`npm run review:pictures`, в сборку не входит): сетка карточек — глагол,
перевод, картинка в светлой и тёмной теме; кнопки «хорошо / переделать /
убрать картинку» и поле комментария. Решение сразу пишется в
`pictures.json` (POST в маленький плагин дев-сервера). Пачки по 100 глаголов
по частоте; «переделать» с комментарием я переделываю в следующей пачке.

Где видна картинка: в карточке словаря — всегда; в играх — только после
ответа, рядом с правильным вариантом, чтобы не подсказывать.

## 2. Местоимения и формы

| Местоимение           | Наст.   | Прош. | Буд. |
| --------------------- | ------- | ----- | ---- |
| אני · я (м.) / я (ж.) | ms / fs | 1s    | 1s   |
| אתה · ты (м.)         | ms      | 2ms   | 2ms  |
| את · ты (ж.)          | fs      | 2fs   | 2fs  |
| הוא · он              | ms      | 3ms   | 3ms  |
| היא · она             | fs      | 3fs   | 3fs  |
| אנחנו · мы (м./ж.)    | mp / fp | 1p    | 1p   |
| אתם · вы (м.)         | mp      | 2mp   | 2mp  |
| אתן · вы (ж.)         | fp      | 2fp   | 2fp  |
| הם · они (м.)         | mp      | 3p    | 3mp  |
| הן · они (ж.)         | fp      | 3p    | 3fp  |

В настоящем времени у «я», «мы» род обязателен — показываем «я (ж.)».
Одна форма часто подходит нескольким местоимениям (אוכל: я (м.), ты (м.), он;
תאכל: ты (м.), она; без огласовок אכלת — ты (м.) и ты (ж.)). Генератор
вопросов это учитывает: правильный вариант всегда ровно один (см. 3.2).

## 3. Игры

Общая схема: раунд из 10 заданий, полоска прогресса, кнопка озвучки на
карточке, после ответа — правильный/неправильный (правильный ответ подсвечен
вместе с иллюстрацией глагола, при ошибке ждём «Дальше»), в конце — итоги со списком ✓/✗ и «Повторить ошибки».
Итого 9 игр, у каждой своя статистика.

Все четыре части открыты сразу; на главной — подсказка «начните с части 1»
и прогресс каждой части. Пуаль и хуфаль участвуют в играх: вместо инфинитива
показывается прош. 3 л. м. р. с пометкой «нет инфинитива».

### 3.1 Часть 1 — глаголы

1. **Иврит → русский**: инфинитив (с огласовками, кнопка 🔊) и 4 перевода.
2. **Русский → иврит**: перевод и 4 инфинитива.
3. **Напиши на иврите**: перевод, ввод инфинитива (системная клавиатура или
   экранная ивритская). Сравнение без огласовок; конечные буквы и вариант
   полного/неполного написания (`variants`) — см. решение 7. Принимаются все
   глаголы с таким переводом (говорить = לדבר / לומר).

Дистракторы: из той же частотной полосы, без общих переводов с правильным
ответом (нет «говорить» среди вариантов к «сказать», если переводы пересекаются).

### 3.2 Части 2–4 — настоящее, прошедшее, будущее (по 2 игры)

1. **Местоимение → форма**: инфинитив с переводом + местоимение
   («הוא · он»), 4 формы того же глагола в этом времени. Дистракторы — другие
   лица того же времени, без совпадающих по написанию с ответом.
2. **Форма → местоимение**: форма глагола, 4 варианта — полные фразы на
   иврите «местоимение + эта форма» (אַתְּ אָכַלְתְּ, הוּא אָכַלְתְּ…), верна
   ровно одна. Русского перевода в вариантах нет (он подсказывал бы ответ);
   после ответа — верная фраза с переводом («ты (ж.) ела / съела») и озвучкой.

### 3.3 Какие глаголы попадают в раунд

Для каждой игры своя «граница»: изучаются первые N глаголов по частоте
(старт — 20). Глагол считается выученным в игре после 3 правильных ответов
подряд; когда выучено 80 % открытых, открываются следующие 10. Внутри открытых
вес глагола = 1 + вес ошибок + вес давности (формула из `alef-bet/src/stats.ts`),
поэтому ошибки возвращаются чаще, а давно не виденные — раньше. В раунде
не больше 3 новых глаголов.

## 4. Менора биньянов

Отдельная страница, кнопка в шапке на любом экране. SVG-менора на 7 ветвей
(пааль, нифаль, пиэль, пуаль, хифиль, хуфаль, хитпаэль). Нажатие на ветвь —
карточка биньяна: значение (действие, пассив, интенсив, каузатив, возвратность),
краткие признаки (приставки, огласовки, дагеш), модели на корне פ־ע־ל
для настоящего, прошедшего и будущего, 3–5 примеров из словаря (ссылки
на карточки глаголов). Тексты пишу я, вы вычитываете.

## 5. Словарь

Поиск в одном поле, тип запроса определяется по буквам:

- иврит — без учёта огласовок, по инфинитиву **и по любой форме**
  (ввёл אכלתי → нашёлся לאכול);
- русский — по переводам, без учёта регистра и ё/е, по началу слова;
- корень — «כתב», «כ־ת־ב», «כ.ת.ב».

Карточка глагола: иллюстрация (если есть), инфинитив, корень, биньян (ссылка
на менору), переводы, таблицы трёх времён с озвучкой каждой формы, ранг частотности.

## 6. Статистика

`localStorage`, один ключ `hebrew-verbs` (версия — поле внутри), все поля проверяются при чтении,
повреждённые данные → значения по умолчанию. На каждую пару (игра, глагол):
показан, верно, ошибок, серия верных подряд, когда видели последний раз.

Страница «Прогресс»: по каждой игре — сколько выучено из открытых, точность,
самые трудные глаголы; сброс одной игры или всего (подтверждение в своём
диалоге, не `confirm()`).

## 7. Озвучка

`speechSynthesis` с голосом иврита (`misparim/src/speech.ts`). Нет голоса —
кнопка 🔊 неактивна, подсказка, как установить голос иврита в системе.

## 8. Стек и устройство

По общим правилам `~/projects/CLAUDE.md`, старт через `/new-web-app`:
TypeScript 7 + Vite, без React (две схемы заданий — выбор из 4 и ввод —
на все 9 игр, состояния немного), oxlint + prettier, vitest + jsdom,
Playwright smoke на телефонном экране, PWA, GitHub Pages, GPL-3.0-or-later.
Отличие от шаблона: **без i18n** — только русский; все тексты в `src/texts.ts`;
это записываем в CLAUDE.md проекта.

Маршруты через hash: `#/`, `#/part/1/he-ru`, `#/part/2/form`, `#/menorah/piel`,
`#/dict?q=…`, `#/dict/<id>`, `#/progress`.

- `src/questions.ts` — генерация заданий и дистракторов для 9 игр.
- `src/answer.ts` — проверка введённого ответа.
- `src/search.ts` — поиск по словарю.
- `src/binyanim.ts` — тексты меноры.
- `src/pictures.ts` — иллюстрация глагола (эмодзи с запасной SVG, своя SVG
