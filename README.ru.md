# Глаголы иврита

[English version](README.md)

Тренажёр тысячи самых частотных глаголов иврита для тех, кто говорит
по-русски: сначала значение, потом настоящее, прошедшее и будущее время.
Работает без интернета (PWA): <https://dmitryweiner.github.io/hebrew-verbs/>.

## Что внутри

- **Четыре части** по порядку: глаголы, настоящее, прошедшее, будущее. Все
  открыты сразу.
- **Знакомство с глаголами.** Сначала часть показывает свои глаголы по
  одному: картинка, инфинитив с озвучкой и переводом, в частях 2–4 — вся
  таблица времени. Игра не спрашивает глагол, с которым вы ещё не знакомы;
  если раунду нужны новые глаголы, сначала идут их карточки.
- **Девять игр**, в раунде десять заданий: в части 1 «Иврит → русский»,
  «Русский → иврит» и «Напиши на иврите», в каждом времени — «Местоимение →
  форма» и «Форма → местоимение». После ответа — карточка глагола, в играх
  времён ещё и фраза с переводом («ты (ж.) ела / съела»). В конце раунда —
  итоги и «Повторить ошибки».
- **Повторение с умом.** Каждая игра начинает с 20 самых частотных
  глаголов. Глагол выучен после трёх верных ответов подряд, ошибки
  возвращаются чаще, а когда выучено 80 %, открываются ещё десять.
- **Словарь**: поиск по любой форме (אכלתי найдёт לאכול), по корню или
  по-русски; карточка глагола с таблицами трёх времён, каждая форма
  озвучена.
- **Менора биньянов**: семь биньянов, их значение и признаки, модели на
  פ־ע־ל и примеры из словаря.
- **Прогресс**: что выучено в каждой игре, точность и самые трудные
  глаголы; сброс одной игры или всех.
- **Настройки**: классические огласовки или полное написание без них,
  транслитерация кириллицей, автопереход после верного ответа. Озвучка —
  голос иврита в системе; в настройках написано, как его установить.
- **Без интернета.** После первого открытия всё работает без сети. На
  телефоне приложение можно установить: в меню браузера — «Добавить на
  главный экран» или «Установить приложение». Прогресс хранится только в
  этом браузере.

## Разработка

```bash
fnm use            # Node из .node-version
npm ci
npm run dev        # дев-сервер
npm run check      # типы + линтер + юнит-тесты
npm run smoke      # проверка в браузере (-- --preview — сборка и офлайн)
npm run build      # → dist/
```

## Источники данных

Формы глаголов строит собственный спрягатель (`scripts/lib/`), сверенный с:

- таблицами спряжений [английского Викисловаря](https://en.wiktionary.org/)
  (CC BY-SA 4.0) — огласовки и пометки глагола;
- [Hspell](http://hspell.ivrix.org.il/) (AGPL-3.0) — написание без
  огласовок; только в скриптах сборки и как тестовые данные, в приложение
  ничего из него не входит;
- [FrequencyWords](https://github.com/hermitdave/FrequencyWords), список
  OpenSubtitles 2018 для иврита (CC BY-SA 4.0) — частотность глаголов.

Переводы на русский и видовые пары написаны вручную и проверены; их формы
спрягает [pymorphy3](https://github.com/no-plagiarism/pymorphy3) (MIT,
только в скриптах сборки). Как сделаны данные — [docs/data.md](docs/data.md).

Картинки эмодзи для устройств, где эмодзи нет в шрифте, —
[Twemoji](https://github.com/jdecked/twemoji) (CC BY 4.0), в
`public/twemoji.json`.

Те же источники приложение показывает на странице «О приложении» (`#/about`).
